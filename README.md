# Portfolio Website

## Project Overview

This project is created as part of the Advanced Teacher Project preliminary stage.

The Portfolio Website is a simple personal website designed to showcase profile information, skills, and project experiences in a professional way. It helps present personal branding and demonstrates basic front-end web development skills.
---

## Features

The website includes:

- Home section with profile photo and introduction
- About Me section
- Project showcase section
- Contact information section
- Responsive design using Bootstrap
- Simple and clean user interface

---

## Technologies Used

- HTML
- CSS
- Bootstrap 5
- JavaScript
- Visual Studio Code (VS Code)

---

## How to Run the Project

### Step 1 — Open Project Folder

Open the portfolio project folder in Visual Studio Code.

### Step 2 — Run the Website

Open the file:

```html
index.html
```

You can run it by:

- Double click the file to open in browser

or

- Right click → Open with Live Server (recommended)

### Step 3 — View the Website

The browser will display:

- Profile section
- About Me
- Projects
- Contact information

---

## Project Purpose

This project helps demonstrate:

- Basic website structure using HTML
- Styling using CSS
- Responsive layout using Bootstrap
- Project presentation and personal branding
- Front-end web development fundamentals

It is simple enough to explain during mockup teaching sessions and suitable for beginner-level students.
